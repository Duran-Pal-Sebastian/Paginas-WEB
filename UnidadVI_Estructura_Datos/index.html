6.1

Búsqueda secuencial

Consiste en recorrer el vector del principio hacia el final, sin que los datos tengan que estar ordenados. Si se encuentra el valor, la búsqueda termina; si se recorre todo el vector sin encontrarlo, se declara fallida.

// Búsqueda secuencial: devuelve la posición (0, 1, 2...) o -1
static int BusquedaSecuencial(int[] a, int t)
{
    for (int i = 0; i < a.Length; i++)
    {
        if (a[i] == t)
            return i;       // encontrado
    }
    return -1;              // recorrió todo y no está
}

// Con centinela: el vector tiene un espacio extra al final
static int Centinela(int[] a, int n, int t)
{
    a[n] = t;               // centinela en A[n+1]
    int i = 0;
    while (a[i] != t)
        i++;
    return i < n ? i : -1;  // si i llegó a n, no estaba
}
Elemento centinela. Se agrega el valor buscado al final, en A[n+1], para que la búsqueda siempre tenga éxito. Así se evita comparar i con n en cada paso. Si el índice llega a n+1, el valor no estaba en el vector original.
Costo. En un vector de 1000 elementos se hacen en promedio unas 500 comparaciones. Es sencillo, pero lento cuando los datos son muchos.

6.2

Búsqueda binaria

Se aplica a vectores ya ordenados y usa la idea de “divide y vencerás”: se examina el elemento central y, según sea mayor o menor que el buscado, se descarta una mitad del vector. El proceso se repite con la mitad restante.

// Búsqueda binaria: el vector debe estar ordenado
static int BusquedaBinaria(int[] x, int k)
{
    int bajo = 0, alto = x.Length - 1;
    while (bajo <= alto)
    {
        int central = (bajo + alto) / 2;
        if (x[central] == k)
            return central;         // encontrado
        if (k < x[central])
            alto = central - 1;     // descarta la mitad derecha
        else
            bajo = central + 1;     // descarta la mitad izquierda
    }
    return -1;                      // no quedan mitades
}

// Ejemplo de uso
int[] datos = { 2473, 2545, 2834, 2892, 2898, 2983, 3005, 3446, 3685 };
int pos = BusquedaBinaria(datos, 2983);
Console.WriteLine(pos >= 0 ? $"Encontrado en la posición {pos + 1}" : "No encontrado");
El ejemplo del libro. Para buscar 2983 en el vector de nueve elementos, se examina el central 2898 (posición 5). Como 2983 es mayor, se descarta la primera mitad. Luego se prueba 3005 (posición 7); como 2983 es menor, queda solo la posición 6, que coincide.
Costo. Con 1000 elementos, la búsqueda binaria resuelve el problema con solo 10 comparaciones en el peor caso. El precio es que el vector debe estar ordenado antes.

6.3

Búsqueda por funciones de hash

En lugar de comparar, se calcula dónde está el dato. Una función hash convierte la clave en un número que indica la posición (cubeta) de una tabla donde se guarda y se busca.

Función hash

Un método común es el de residuo: h(k) = k mod m, con m el tamaño de la tabla. Para texto se suman los códigos de los caracteres y se aplica el mismo residuo.

Colisiones

Dos claves distintas pueden dar la misma posición. Se resuelven con encadenamiento (una lista enlazada por cubeta) o con direccionamiento abierto (buscar otra casilla libre).

Rapidez

Con una buena función y pocas colisiones, buscar cuesta casi una sola operación sin importar cuántos datos haya. Si todo cae en la misma cubeta, se vuelve una búsqueda secuencial.
